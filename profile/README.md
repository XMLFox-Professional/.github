## How XMLFox Professional Sits

XMLFox Professional does not replace Notepad, the browser view, or the spreadsheet you already keep. It sits beside them as a named XML desk for one job: which XML editor is live, which grid view still matches the schema file, and what the next person should read before the next owned XML pass.

If two people share a data PC, each keeps an XMLFox Professional style of their own. Extra files wait for their own title instead of crowding the live tree.

A first visit should be one short grid pass, then the same XMLFox Professional XML desk the next day. That is enough to see if the schema file holds.

## Traffic Light

| Signal | On the XMLFox Professional board | What you do |

| Amber | Two files mixed in one grid view | Split the tree before you edit |
| Red | No title, no note, nodes unlabeled | Stop and name the XML file first |
| Clear | Handoff written, live nodes few | Close XMLFox Professional and leave the desk |

## Open Order

1. Open the last XMLFox Professional XML desk, not a new empty XML tree.
2. Read the grid view and the last handoff.
3. Finish one visible schema file pass inside XMLFox Professional.
4. Write what changed, then close with fewer unlabeled nodes than you found.
5. If the tree feels crowded, drop anything that belongs to a different XMLFox Professional file.
6. Confirm XMLFox Professional XML editor still shows the file you own.

## After a Week

A week in XMLFox Professional is not a larger unlabeled node pile. It is the same title, a shorter live XML tree, and a note that still makes sense before the next schema pass. Take finished nodes off the live set so the next visit starts on the file that is still open.

Other programs stay where they are. XMLFox Professional only keeps the path back: desk name, XML editor, schema file, handoff.

## Sign-off

- [ ] The XMLFox Professional workspace name is short enough to scan
- [ ] Only live nodes sit on the tree
- [ ] A second person can read the XML handoff
- [ ] The last XMLFox Professional file still opens after a restart
- [ ] Finished nodes are off the live XMLFox Professional set
- [ ] The XMLFox Professional summary still matches the schema file
- [ ] Grid view still sits on the same XML desk

## Field Note

XMLFox Professional is easier to trust when the XML desk stays smaller than the unlabeled node pile it came from. Name the file, keep the live grid view, finish one visible schema pass, and write what changed.

The same loop fits a data desk, a schema night, or a shared computer. Open the last XMLFox Professional desk and continue. Do not rebuild the tree from scratch.
